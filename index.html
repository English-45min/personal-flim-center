影视发现中心

数据源设置

优先填写个人 TMDB API Key，或填写已部署的 ESCAPE API Worker 地址。API Key 仅保存在当前浏览器，不要在公共设备使用。

说明：本版可直接调用 TMDB API（需个人 Key）；Worker 代理入口为预留兼容接口。尚未部署并配置对应 Worker 路由时，不能使用云端代理。TMDB 的观看渠道、地区可用性与实际价格请以流媒体平台为准。

正版影视平台 · 搜索与访问
